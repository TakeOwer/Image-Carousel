# Forum Image Carousel

A phpBB extension that creates a responsive carousel displaying the first image from selected forums.

## Features
- Responsive carousel displaying the first images from selected forums
- Mouse hover scrolling on desktop
- Touch gestures for scrolling on mobile devices
- Image lazy loading for optimized performance
- Intelligent preloading of the next slide
- Intersection Observer API for modern browsers with fallback support
- ACP configuration for enabling/disabling the extension
- Selection of forums from which to display images
- Enhanced tooltips showing topic title, author, and posting date
- Links open in a new browser tab for better user experience
- Multilingual support (English and Italian)

## Installation
1. Download the extension
2. Copy the entire contents of the extension to `/ext/salvocxortesiano/carousel/`
3. Navigate in the ACP to `Customise -> Manage extensions`
4. Look for `Forum Image Carousel` under the Disabled Extensions list, and click its `Enable` link

## Configuration
1. Navigate in the ACP to `Extensions -> Forum Image Carousel`
2. Configure the extension settings as needed
3. Save the configuration
